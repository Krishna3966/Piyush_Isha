
LLM
LLM stands for large language model. 
LLM is just a computer programme that has been trained on a massive amount of text. 

LLMs do not think like a human. They do not understand things like we do.
They simply look at your input and start predicting what should come next. 

Whenever we use ChatGPT, Claude, or any AI tool, just remember this one line: it's a very advanced prediction machine. 

Agents

LLM will understand the instruction, while the agent is going to take action on my behalf.

User -> Prompt -> LLM -> Agent -> Tools

MCP - Model Context Protocol 
It standardises how tools and AI talk to each other.

Playwright MCP allows the AI agent to use Playwright as a tool. 

LLM is the brain. 
Agent is the one that performs actions. 
MCP is the bridge that connects AI with tools. 
Playwright MCP allows AI to automate browsers.
Copilot helps you write code faster inside your editor. 

AI can assist you, but it cannot replace your thinking.
